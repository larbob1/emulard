# BVH builder completion candidates

The reviewed fork reports 49 of 52 builder programs translating, with some host pipeline creation failures on 32-lane GPUs. These are upstream reports, not verified coverage for this project. Marvisak's range analysis and the independent translator's atomic implementation were reviewed in prior revisions. Neither supplies a verified drop-in dynamic structure builder for this runtime.

The optional wave-wide retry used to consider only the first available control-flow representation. It now tries each available representation, including constant-edge threading, in order and still accepts only successful host-compatible lowering. The existing opt-in for wave-wide branch barriers is unchanged because the upstream project reported device loss with that experimental path. Spilled compute programs, including the builder, now use strict local-wave policy: the unproven approximate half-wave fallback is not accepted. This may lower apparent coverage, but avoids claiming a valid structure from an approximate translation.

The direct dispatch path already disables the builder after a binding failure. The indirect dispatch wrapper now does the same for failures inside its execution path, including argument preparation, pipeline binding and signature creation. It does not detect failures before the wrapper is entered or roll back previously recorded GPU work. The existing all-or-none pipeline gate and quarantine behavior remain in effect.

All new source anchors were checked against the pinned sources. Compilation and actual builder output are not verified by these changes. The remaining prerequisite is a local run of the lawfully available program, with the builder quarantined, collecting failed pipeline counts, translation reasons and completed memory feedback. Do not enable normal builder writeback until the missing stages, unresolved memory faults and structure correctness have been tested. No proprietary program or data is stored in this repository.
