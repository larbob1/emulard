# Group-uniform control proof

The split-wave candidate previously refused any multi-console-wave group with branching control when the translator needed group-wide meetings. This revision accepts a conservative acyclic subset when all reachable branch conditions can be proven group-uniform. The seed values are recognized dispatch parameters and compute group IDs. Ordinary SGPRs are not inherently uniform across console waves. The transfer function accepts a small explicit whitelist of scalar integer arithmetic and comparisons, rejects mask values and unknown producers, and accepts an acyclic phi only when all incoming values are proven uniform. Indirect exits and cycles are rejected. The earlier per-lane convergence checks remain authoritative.

The existing wave-tail CI suite includes synthetic checks distinguishing unproven scalar inputs from known uniform dispatch inputs and refusing cyclic control. Source compositions were verified against the pinned baseline. This does not prove divergent loop convergence, arbitrary group layouts or correctness of real builder shaders. It is not full Wave64 support. The latest full runtime validation before this revision passed at a889da8; newer synthetic checks passed. Hardware testing is still required. The upstream projects remain read-only.

## Conditional scalar loops

The next candidate extends the proof to loop-carried scalar values. Pure definitions and valid phis start as candidates, then a reverse dependency worklist removes any value depending on unproven input. All reachable structured branch conditions must still be uniform. Entry phis, special operands, memory-dependent conditions, lane masks, wide branches and unconditional back edges remain outside this proof. This establishes an inductive uniformity condition, not that the existing iteration cap can never be reached. It enables the converged backward permutation path in eligible scalar loops. Independently branching waves remain refused. Half-wave exchange now uses atomic stores to avoid concurrent non-atomic shared-memory writes. Atomic overhead is not measured.

A scalar-counter fixture and an unknown-initial-value variant extend the existing wave-tail suite. Both runtime source compositions were checked against pinned source. The prior backward permutation revision 7e97c4b passed both runtime configurations. These new runtime changes are not yet compile- or GPU-verified. No actual builder or shadow-mask output is claimed.
