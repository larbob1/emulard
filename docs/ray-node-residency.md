# Ray-node residency checks

The raw memory directory maps a missing page to a null buffer. Previously, zero-filled node coordinates and child pointers could be interpreted as a valid box hit. The ray intersection path now retains the directory lookup's mapped predicate. It reports faults through the existing mechanism and returns the triangle miss result for a missing triangle node or four invalid child pointers for a missing box node. Wide boxes require both of their 64-byte portions to be mapped; the second lookup is reused instead of adding another directory read. Descriptor-backed nodes retain their existing path.

This is a conservative missing-data fallback, not restored lighting: a missing node cannot be traversed correctly until its actual contents are resident. It prevents one form of bogus traversal and is intended to improve stability while mapping catches up. No missing GPU writes are replayed, no structure-builder gate is removed, and no claim is made that a rendered scene is correct. The existing ray-directory lowering regression exercises both forms in CI. Both pinned source compositions were checked. Runtime compilation and GPU execution remain pending for this revision. Earlier 7e97c4b passed both runtime configurations.
