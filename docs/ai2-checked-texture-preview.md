## Helper contract

RecordingBuilder::select captures selected kind/ordinal before Target::new, retains refusal, never deduplicates by owner pointer; capacity failure poisons the builder so no inventory can be finalized. Nonselected resources create no entry. finish records only after complete per-target validation, retains both refusals and recorded resources in immutable inventory; evaluate attaches an external execution label and reevaluates each ordinal without consuming it. Labels and ticket identity are not allocation-generation or completion proof.

Narrow explicit typed formats 16 (R32G32_FLOAT, 8 bytes), 36 (R16G16_UINT, 4), 41 (R32_FLOAT, 4), 61 (R8_UNORM, 1). This covers the numeric built-in texture selections and the prior R8 fixture, not proof of actual host compatibility or every layout. Require exact host numeric format, actual D3D12 plane count 1, actual host sample count 1, normalized guest layout 2D/sample1/block1, addressable swizzle, active mip dimensions, exact array/mip inventory and row bytes, aligned pitch/offset, nonoverlapping full pitched spans, checked sizes and actual buffer width before issuing any copy. Preview bounds 256 MiB for guest/host extents and 4096 entries/subresources; these are conservative preview refusal limits, not gameplay policy. Preview-owned vectors use fallible allocation; existing Target::new/layout internals are unchanged and their internal allocations are not made fallible by this preview. The existing resource API normalizes guest sample count and does not expose original descriptor via this helper; no claim that raw guest sample-count identity is established.

Caller obligations for unsafe preview functions: live resource for selection; open list and COPY_SOURCE state for recording, retain all GPU leases until actual retirement, no replay of invalid/reset objects; before evaluating a recorded entry prove actual healthy retirement for that occurrence and stable readable/writable backing, external writer/alias exclusion over preservation and transfer. No boolean or caller-created token is treated as verified GPU proof. The helper cannot independently prove these prerequisites, and no live caller is connected. Mapping read guard and ticket lock retain existing order, exclude relevant remap/invalidation only, not other CPU/physical-alias writes. No resource accessor or change to external lifetime/lock policy.

Landing checks span/width/range, full private preservation via checked same-process kernel copy, successful Map has RAII Unmap exactly once (including null pointer), tile every exact subresource, then existing write-watch effect before a single full-span transfer. No zero-fill fallback, retry, prefix injection, new success counter, terminal notification or override of legacy diagnostic mode/ask flags. Each call records attempted/requested/status/done; classify full exact status/count as ByteOutcome::Complete, successful short count as incomplete, failed status or impossible counts as unknown, coherent nonattempt as not attempted. No rollback claim. SemanticDelivery is deliberately only Unresolved, even on complete byte receipt. No production success is inferred, no actual selected gameplay formats/route or writer stability established.
