## Independent source-order model executed

32,768 three-call traces, 98,304 operations, both list identities, read/write, fault append, named append, heap refusal. Fault append precedes numbered snapshot; name append follows. Model compares ordered refresh/write registration events, first-use state, and missing per-list refresh coverage; zero original/candidate mismatches. 6,528 traces contain at least one modeled missing refresh registration in both versions. This is not a probability or measured runtime defect. Example A names copy0, B names copy1, A repeats with no new name: A still only has Refresh(copy0), while B has both. Baseline explicitly assumes other list submission supplies refresh. Heap refusal and fault append create analogous pre-snapshot boundaries. Do not silently fix baseline semantics as part of #71.
